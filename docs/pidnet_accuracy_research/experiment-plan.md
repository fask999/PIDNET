# PIDNet 精度实验计划：Cityscapes 与 CamVid

先建立可追溯的单尺度基线，再按失分类型做单项消融。精度优先，允许适度增加推理时间；单尺度改进与离线 TTA 分开排名。以下是待执行方案，没有训练结果或速度测量。源码现状见 [仓库审计](repo-audit.md)，方法依据和跨论文比较限制见 [文献笔记](literature.md)。

## 1. 数据、初始权重与基线 B0

| 数据集 | 选方案与权重 | 方案冻结后的测试 | 标签和当前状态 |
| --- | --- | --- | --- |
| Cityscapes | fine `train.lst` 2,975 张训练，独立 `val.lst` 500 张选型 | `trainval.lst` 3,475 张重新训练，独立 `test.lst` 1,525 张；本地只导出，交官方评测 | 19 类；当前 `gtFine`、`leftImg8bit` 软链失效。test 名单只有图像，本地不能算 test mIoU。 |
| CamVid | `train.lst` 367 张训练，独立 `val.lst` 101 张选型 | `trainval.lst` 468 张重新训练，独立 `test.lst` 233 张；标签齐备后本地评估 | 11 类；当前仅有名单占位。仓库默认 CamVid 配置使用 `trainval`，本轮选型必须显式改用 `train`。 |

- 开跑前先清点名单中每个图像及标签的真实路径、可读性、尺寸和 ID/调色板。保存名单及文件清单哈希、去重结果和数据版本；检查 `train∩val=∅`、`trainval=train∪val`、`trainval∩test=∅`。额外池和教师也核对来源，检查跨数据集重复和 CamVid 视频的近邻帧/近重复情况；保留标准名单，记录可疑样本及其影响。测试集不得参与采样统计、阈值、停步或 checkpoint 选择。最终 trainval 事先固定训练步数、学习率日程和取权重规则（建议最后一步），无独立 test 标注前不报告得分。
- Cityscapes 的原始灰度 `*_labelIds.png` 按官方映射变为 `trainIds` 0–18，void/填充统一为 255；若输入本来是 `*_labelTrainIds.png`，显式走已编码分支并验证值域，避免二次映射。用原始 ID 7→训练 ID 0、原始 ID 0→255 和 255 padding 做样例回归。Cityscapes test 或官方 val 评估须把预测 0–18 映回官方 `labelIds`，保存原尺寸单通道 PNG；`instanceIds` 单独保留给 iIoU。CamVid 用固定 RGB 调色板映射 0–10，未映射颜色转 255 并记录频次。标签缩放用最近邻，图像沿用固定的 RGB、ImageNet 均值/方差及图像插值。
- **B0：修复后训练，主头原图单尺度、无 flip。** 精度主线建议先锁 PIDNet-M（Cityscapes S 可先做工程筛查，L 作为单独的容量对照；变体之间不能替代同变体消融）。保留原训练随机缩放/裁剪、类权重、P 辅助 CE、主头 OHEM、旧 Canny 目标及 D BCE、原 BAS（仓库 SB 项：D 的 sigmoid >0.8 后选主语义像素）。训练增强和测试单尺度是不同开关。仅修复第 2 节的运行/评估问题；B0 不纳入有效像素边界目标、采样、蒸馏、结构或 IoU 损失改进。
- Cityscapes 从已知来源的同一骨干初始化开始。CamVid 若按仓库方向做 Cityscapes→CamVid 迁移，使用已核实来源且无 CamVid held-out 重复的同一 Cityscapes checkpoint，明确重新初始化不匹配的 11 类头；如缺该权重，先统一用可追溯的 ImageNet 初始化。两种初始化不要混在同一组。现有 `PIDNet_L_Cityscapes_from_mmseg.pth.tar` 的训练 split 未核实，旧 loader 还留下两个未加载的随机 bias；只能用于加载/前向烟测，不给 B0 或教师提供权重，不据此报告 mIoU。
- 每组配对固定数据、公共层初始化、训练 crop/基础尺度、总优化器步数、有效 batch、每卡 batch、BN/OHEM 归约方式、SGD/poly 日程、AMP 和验证频率，记录 commit、解析后配置和随机种子（建议 304、305、306）。逐步保存学习率、样本曝光和有效标签数；R3、R8 只允许变更其声明的采样或数据因素。新增层单独设种子，共有层的初始张量核对哈希或一致性；若从 B0 checkpoint 微调，无改动对照也从同一 checkpoint 训练同样步数、用同一优化器初始化。CamVid 先明确一个实际步数日程，例如按 121 次 train-only 遍历换算步数并把 poly 终点设为同一总步数；旧入口 121 轮停止、按 200 轮算 LR 是历史复现协议，单列。保存 val 选中与固定最后一步的成绩；选中权重按独立 val mIoU、同频率并预定并列规则（例如取较早一步）。

## 2. 工程门槛与分阶段运行

| 门槛 | 预期行为与验证 |
| --- | --- |
| G0：短 CPU 烟测（合成张量/可读样例） | 使用审计所述环境或登记等效依赖。统一 loader 并检查裸 key、已知前缀、错形状、主头和各分支覆盖率；评估权重除明确允许且不参与当前路径的键外须完整匹配，迁移单独列出允许缺失的分类头。训练输出 `[P, 主语义, D]` 分别为 `[K,K,1]` 通道，推理强制主语义 `K` 通道；用各头预测不同的样例防错选。验证 loss/反传在全 ignore、BAS 无候选、OHEM 同分和 batch >1 关闭 OHEM 时有限；正常 OHEM 保留原已满足保留量的候选。验证 Acc/混淆矩阵忽略 255，checkpoint 恢复不覆盖更优 best，并核对 CamVid 最后一步 LR。测试合规尺寸与奇数 H/W 还原、反转 flip、导出标签及 RGB 映射；合成验证覆盖空边界与小目标统计。CPU 烟测只证明这些路径可用，不能证明模型精度、训练稳定性或 GPU 速度。 |
| G1：数据就绪后的有标签训练烟测 | 仅在 G0 和数据门槛通过后，用目标训练配置短跑（例如 50–200 步），验证有限损失/梯度、实际更新、样本与有效像素数、P/I/D 梯度、加载与续跑、独立 val 前向/导出和显存；记录失败触发条件。短跑得分只用于诊断。 |
| G2：配对正式实验 | 先跑一组同种子 B0/候选筛选；有希望的方案做至少 **3 个配对种子**复验，报告每对差值及其均值、标准差和方向。改变目标数据集、模型变体或训练配置，重新建立对应 B0。数据未就绪时，G1/G2 阻塞；不以 README、论文或未知 split 权重填补实测。 |

图像尺寸统一契约：先按该次推理倍率缩放；若翻转，翻转未补齐的图像。右/下补到 `ceil(H/8)*8 × ceil(W/8)*8`，用固定填充值（建议沿用归一化前 RGB 0）；训练标签对应补 255。把主头 logits 双线性插值到补齐尺寸，裁到该次缩放尺寸，去翻转，再把 logits 还原到显式原始 `(H,W)`。TTA 在统一域聚合后才 `argmax`；禁止把 HWC 的尾两维当高宽，也不对已 argmax 的标签做双线性插值。固定并记录外层 `align_corners`（B0 沿用配置值），不要顺手改内部插值。整图超显存可另设同窗宽、重叠、融合规则的滑窗评估组，注明通过次数和时延，不与整图组互相代替。现有 `TEST.FLIP_TEST/MULTI_SCALE` 无消费者，执行前须实现或验证真实推理入口，不能仅改 YAML 就认作启用。

4 GiB GTX 1650 是本机验证限制；保留 OOM 结果，不因本地容量放弃高精度候选。若正式训练需缩小 crop、开 AMP、换卡或调整 batch，所有相关对照使用同一新协议并重建 B0。梯度累积不能复现更大每卡 batch 的 BN/OHEM 行为；PPM 的 1×1 BN 对每副本 batch=1 也可能报错，改 BN、冻结策略或换有效 batch 时都要重新配对。

## 3. 实验矩阵

默认对照为对应数据集、变体和种子的 B0。R1 不重训；R2–R8 默认先单独对照，表中的子组只改变写明的变量。选定多项后按固定顺序加回并逐步复验，保留最终组合与“去掉某一项”的结果；不把单项增益直接相加。

| ID | 执行与对照 | 优先看什么 |
| --- | --- | --- |
| **R1 同权重分辨率、flip、TTA** | 固定 B0 checkpoint、val 名单、主头和预处理：`1×` → `0.75×/1.125×/1.25×` 各自 SS；`1×` vs `1×+flip`；`{0.75,1,1.25}×` 的等权概率平均，无 flip 与每尺度双向 flip 各一行。先在原图坐标统一 logits，再各自 softmax，聚合后 argmax；保存权重哈希、真实 H/W 和前向次数。 | SS 放大是否补回小实例；flip 或 MS 改善的是漏检、类别混淆还是边界。SS 放大可按部署成本门槛选型，TTA 分列为离线档。 |
| **R2 有效边界目标与 BAS** | B0 的旧 Canny 和 D 全像素归约保留。R2a 旧 Canny＋有效 D 掩膜；R2b 在同掩膜下换成增强后的有效类邻接边界。R2a/R2b 都保持 BAS 开启；再给 B0/R2a/R2b 各做 BAS 关闭对子。 | R2a−B0 看掩膜；R2b−R2a 看目标；每组 BAS 开/关看语义边界项及相互作用。看主语义 F1、mIoU 和 D 正例/梯度统计。 |
| **R3 罕见类/小目标 crop** | 固定训练图像抽样、缩放和 crop 尺寸；R3a 用部分 crop 锚在罕见类像素，R3b 用相同比例锚在小实例，各自对照随机裁剪。首轮可设 25% 定向概率，不足时回退随机；训练集统计确定罕见类及面积阈值。 | 记录 crop 命中/回退率、每类像素与实例覆盖；看小实例召回、逐类 IoU 及背景误报，验证模型是否真的见到更多目标。 |
| **R4 像素 KD / CWD** | 同一冻结教师、学生初始化、增强、有效掩膜、对齐网格和训练步数，对照无 KD、像素类别 KL、类别通道空间 KL。教师须有可追溯的 train-only 来源且与学生类序一致，先在同一 val 评估教师；更换教师或外部数据预训练单列。 | 看各类混淆、边界和小实例变化；报告教师推理/缓存的训练成本。学生导出不含教师。 |
| **R5 stride 4 局部细化** | 在共享 1/4 浅层特征上训练一个轻量残差头。固定同一 B0 和残差头 checkpoint，从相同 1/4 网格挑 K 个位置：可复现的 random、主头 top2 margin、只用 D、D＋margin。另测同一轻头全网格的稠密版作为精度和成本对照。 | 等 K 比较选择器；用稠密轻头判断稀疏选择是否值得。看主语义边界 F1、小实例召回、增量 p95 和峰值显存。 |
| **R6 I 路 context 单改** | 在 PIDNet-S/M 的 I 路 PAPPM 里只改一处上下文，例如将 scale3 池化从 `17/8/pad8` 改为 `25/8/pad12`（kernel/stride/padding）；其余分支、PPM 通道和 Bag 不变，保持输出网格与参数形状，验证最小输入。若测试 DAPPM 替换或更宽 I 路，另起对子。 | 先看大区域/相似类别混淆，再查边界、参数量、p95 和显存。 |
| **R7 主语义 IoU/边界损失** | R7a 只在主头 OHEM 旁加 Lovász-Softmax，覆盖所有有效标签；固定按图聚合并记录系数。R7b 可选，在 R7a 基础加 ABL，看其独立增量；若需要判断 ABL 自身作用，再做 B0＋ABL。P、D、BAS 保持不变。 | 看 mIoU、iIoU、关键小类和有效边缘数；ABL 保留原方法的梯度截断，空样本、AMP 有限性单独核对。 |
| **R8 额外数据、伪标签、强初始化** | B0/fine-only 对照下分别试 R8a 额外人工标注、R8b 固定教师给同一额外池打离线伪标签、R8c 同训练集只换可加载且来源可追溯的更强初始化。各自声明训练来源和类别映射，不能把三个因素合成一行。 | 额外样本按来源去重，验证类覆盖和近边界噪声；报告 fine 与额外样本曝光、阈值下每类接受率及计算开销。该组独立于同数据主榜。 |

**R2 实现口径。** BAS 是仓库 SB 辅助语义损失；关闭只令该项权重为 0，D BCE 和 Bag/Light_Bag 门控都继续工作。R2a/R2b 使用同一个 D BCE 有效掩膜，例如 `y!=255` 且到最近 void/填充距离大于预定半径 `r=2 px`，从最终训练 crop 标签得出。R2b 在缩放/裁剪后找两端有效的 4 邻域异类像素，对两侧标记并膨胀 2 px，截在有效掩膜内；R2a 保留旧 Canny 输出。两臂只在掩膜内计算原式正负权重和均值；有效像素为空、或有效边界二值标签只有一类时，返回可反传的零（后一项保持旧加权 BCE 的行为）。若全负批次过多，另在固定掩膜及边界目标上单独试单类批次使用普通 BCE。BAS 开启组仍用有效语义标签和预测 D 阈值筛选；GT 边界带向预测门的过渡或软权重留作开/关消融之后的独立方案。记录每步 D 有效像素、正例率、全负批次及 BAS 选中数。

**R3 控制变量。** 只用 train 标签定义低频类（例如按含该类的训练图数取后 1/4）及原图小实例面积（首轮可用 `<32² px`）。先照原方案抽图和缩放，再在该图候选类/实例中抽锚点；锚点允许随机偏移但须落入 crop。CamVid 的小目标取语义连通分量代理，单列。

**R4 控制变量。** 用同一增强后的图像几何和各自固定的输入归一化，`KL(teacher || student)` 两臂共用 `T`、`T²`、有效像素及同样的选参预算。像素 KD 沿类轴 softmax、按有效像素平均；CWD 在每类通道仅对有效空间位置 softmax、按类平均；空掩膜跳过，记录各损失系数和幅度。在线/缓存上下文须固定；教师若只提供组合语义分数，先定义转换及归一化后才进入相应 KD，首轮优先使用有可对齐 logits 的教师。

**R8 控制变量。** R8a/R8b 匹配总步数与 batch，保留每步相同的 fine 槽位并让 B0 对照在其余槽位重复抽取 fine 样本，同时报告 fine 曝光差异；伪标签的低置信像素 ignore，不直接用于 D 的硬边界监督。若要区分更多数据和更多训练，另设延长 fine-only 对照。

**R5 实现口径。** 在共享 `layer1` 后取 1/4 浅层特征，结合上采样的主语义 logits，输入轻量逐点残差头（可拼接浅层 3×3 邻域）。第一轮冻结 B0 权重及 BN 统计，仅训练同一个残差头：末层零初始化，训练图上将稠密修正后的 logits 恢复到标签坐标，用有效像素 CE 监督。之后在同一 val 和 checkpoint 上只切换推理选择器。候选只在真实输入区域，固定 `K=max(1,ceil(0.10×有效格点数))` 并记录每图数；random 按样本 ID 和固定种子取无放回位置，margin 优先选择 softmax 前两名概率差最小者，D-only 选 sigmoid 后 D 分数最高者，D＋margin 对同一 D 分数与小 margin 各按百分位排名后等权求和。D 分数取原训练 D 单通道头，显式接入推理并计入两个 D 选择器的代价；规定并列时按坐标顺序。仅对所选点 gather 邻域并算残差，回填所选格点，未选处保留原 logits，然后按第 2 节共同还原原图。增加不应用残差的同一 1/4→原图对照，检查二次插值影响。稀疏臂不能先把残差在全图算完再遮罩后宣称省算；全网格轻头不是同 K 对照，报告实测代价，必要时另测减宽的稠密头接近同一 p95。

## 4. 指标、成本与决策

| 类别 | 同一 val 原图坐标下的报告口径 |
| --- | --- |
| 区域语义 | 累加有效像素混淆矩阵，固定 19/11 类，报告 mIoU、每类 IoU、各类有效像素/缺席标记，并明确固定类宏平均如何处理零 union（沿用仓库规则则记 0）。两数据集分表；Cityscapes 同时保留官方评估读数，核对口径差异。 |
| 语义边界 | 从最终主语义 argmax 和真值各取两端都有效且类别不同的 4 邻域，按端点类别分别画边界。使用共同 GT 有效域；对每个欧氏容差 `τ=3,5 px` 排除距离 void/填充 ≤τ 的边界点。预测点匹配 τ 内任一同类真值点计 precision 命中，反向计 recall 命中，先跨图累加分子分母，再报告 micro F1 及关键类 F1。只有一侧为空的类计 0，两侧均空列 N/A，图外不视为语义边界。D 的二值输出质量独立列，不冒充最终语义 F1。 |
| 实例与小类 | Cityscapes 用官方脚本、`labelIds` 与 `gtFine_instanceIds` 报 class iIoU，按官方可评实例类解释；无实例标注则缺项。按原图真值实例有效面积 `<32²`、`[32²,96²)`、`≥96² px` 分桶，排除 void 和 crowd/group，按类/桶报告实例数、实例内像素召回的实例平均与达到 50% 像素召回的实例比例。细杆/灯/标志看逐类 IoU 与边界 F1；不从 iIoU 推导。CamVid 若无实例 ID，用同类 8 邻域 GT 连通分量做面积分桶和相同召回计算，明确它是语义代理（相连物体会合并），不报作 iIoU。 |
| 端到端延迟与显存 | 同设备、软件栈、功耗模式、精度、batch=1、样本列表/顺序与存储/缓存条件。统一从内存中编码图像字节开始计时，含解码、缩放/归一化、pad、H2D、全部前向、裁回/TTA、argmax 和输出掩膜回 CPU；不含磁盘读写和可视化。用设备同步围住每张计时，预热至少 30 张，固定至少 200 次图像处理（CamVid val 可用全部图像重复同顺序），同协议多轮报 p50/p95 与样本数；同步记录峰值 `allocated`、`reserved` 和 OOM。可另列纯前向延迟、参数量/FLOPs，勿与端到端列互比。 |

执行顺序：数据清点和 G0 → 两套独立 val 的 B0 → 同 checkpoint 的 R1 加失分诊断 → R2/R3 训练消融 → R4/R7 训练方案 → R5/R6 结构改动 → 有明确来源后再做 R8。优先级可随诊断调整：错位先做 R2、漏检先做 R3、类混淆先做 R4 或 R6；R5 仅在细化存在上限空间时投入，ABL 仅在主要问题是已存在边界的位置偏差时排入。先在 Cityscapes 建立统一对照，再在 CamVid 的独立 val 复验入选项；未在 CamVid 验证的结果不推广到 CamVid。

以下是开跑前可调整并冻结的**工作门槛，不是用户承诺或预测**：与配对 B0 比，主要目标指标至少 2/3 种子同向；通常保留平均 `ΔmIoU ≥ +0.5` 个百分点的候选。专项候选同时满足整体 `ΔmIoU ≥ −0.2` 和至少一个专项改善（3 px F1 ≥ +1.0 点，或 class iIoU / 小实例召回 ≥ +0.5 点）。关键类的平均 IoU 若下降 ≥1.0 点须检查具体代价与样例。部署候选可先用同设备 `p95 ≤ 1.25×B0` 且不超过目标设备显存预算作工作线，超线方案分列为精度档。分数差异以百分点表示，保留配对原始值及各样本桶数；种子少或小桶样本不足时保留不确定性，不凭一项小幅提升定胜负。

每次运行保存 `run_id`、矩阵行号、代码与数据哈希、种子、有效配置、硬件软件、初始化/教师及选中 checkpoint 哈希、命令、日志、原图预测和指标文件。方案冻结后用同一发布规则重训 B0 和最终候选，评估独立 test；Cityscapes 只有实际官方返回结果才填写 test mIoU，CamVid 仅在 233 张有标签的独立 test 完整评估后填分数。
